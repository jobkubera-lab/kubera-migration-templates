# Kubera Migration Templates

> **Status: supporting template library — not an active KUBERA product.**

This repository preserves reusable job-application document templates.

## Current contents

| File | Language | Purpose |
| --- | --- | --- |
| [`cv/cv-template-en.md`](cv/cv-template-en.md) | English | General CV structure |
| [`letters/cover-letter-en.md`](letters/cover-letter-en.md) | English | General cover-letter structure |

At the moment, the repository does **not** contain complete Russian or Hindi template sets. Earlier wording suggesting RU/EN support, planned Hindi support, or weekly updates was inaccurate and has been removed.

## Use

Treat these files as editable starting points. Before sending a document:

1. replace placeholders with the applicant's real information;
2. tailor the document to the actual vacancy;
3. remove unsupported claims and invented experience;
4. check spelling, dates and contact details;
5. have the final version reviewed by the person who will submit it.

## Maintenance

This is library material. Additions should be concrete templates with a clear purpose, language and example use case. Do not claim a language is supported until the corresponding files actually exist.
